# Quest Manager Web AI

Unity 게임 프로젝트에서 사용하던 NPC 퀘스트 시스템을 웹 서비스와 AI 기능으로 확장한 포트폴리오 프로젝트입니다.

## 프로젝트 목표

게임 내 퀘스트, NPC, 보상, 일일 할당량 시스템을 웹에서 관리할 수 있도록 만들고, AI를 활용해 퀘스트 생성과 설명을 보조하는 기능을 구현합니다.

## 주요 기능 예정

- NPC 관리
- 퀘스트 생성 / 수정 / 삭제
- 퀘스트 수락 / 완료 처리
- 보상 관리
- 일일 할당량 퀘스트 관리
- AI 기반 퀘스트 설명 생성
- AI 기반 보상 추천
- 관리자 페이지

## 기술 스택 예정

### Frontend
- React
- TypeScript

### Backend
- Spring Boot 또는 FastAPI

### Database
- MySQL 또는 PostgreSQL

### AI
- OpenAI API 또는 LLM API
