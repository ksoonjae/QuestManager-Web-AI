# Planning

## 프로젝트 배경

기존 Unity 게임 프로젝트에서 NPC가 도움을 요청하고, 플레이어가 퀘스트를 수락하고 완료하면 보상을 받는 시스템을 만들었다.

이 시스템을 웹 서비스 관점에서 다시 설계하여, 퀘스트와 NPC를 관리할 수 있는 관리자 도구로 확장한다.

## 핵심 도메인

- NPC
- Quest
- Reward
- Daily Task
- Player
- Quest Progress

## 목표

- 게임 시스템을 웹 서비스 구조로 재설계한다.
- CRUD, 인증, DB 설계, API 설계 능력을 보여준다.
- AI를 활용한 퀘스트 생성 기능을 추가한다.
